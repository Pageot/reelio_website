## Add your first folder

With no library yet, the Gallery shows a **Welcome to Reelio** panel. Click **Choose folder…** (or **Add library** in the toolbar) and pick a folder in the Windows folder picker.

If the folder has subfolders, Reelio first opens **Choose folders to scan**: every subfolder is ticked. Untick the ones you want Reelio to skip, then click **Add library**.
