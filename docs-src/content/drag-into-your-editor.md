## Drag a clip out of Reelio

Press on a video tile, drag it out of the Reelio window and release it over your editing app (for example Premiere Pro or DaVinci Resolve) or over a File Explorer window. Reelio hands the video over as a regular file, so the app receives the clip itself.

## Where you can drag from

Every video tile in Reelio can be dragged, wherever it appears:

- the Gallery and folder pages,
- search results, so you can [search](/docs/search/) for a clip and drag it straight from the results,
- tag pages, so a set of clips you tagged for a project is one drag away (see [Tags](/docs/tags/)),
- the sidebar views, such as Favorites, Recently played and Random videos.

In the **Details** view, video rows can be dragged the same way as tiles. See [Sort and views](/docs/sort-and-views/).

## Dropping on File Explorer copies the file

When you drop a clip on a File Explorer window, Explorer treats it as a copy: the clip is copied to the place you dropped it, and the original stays where it is, in your library.

## What you cannot drag

- Folders: folder tiles and folder rows in Details cannot be dragged, in or out of Reelio. To use a whole folder in another app, open it in File Explorer: right-click any video inside it and choose **Show in folder**.
- A tile onto another tile: dropping a Reelio video tile on another tile does not set it as that tile's cover. Covers only come from image files dragged in from outside Reelio, for example from File Explorer. See [Video covers](/docs/video-covers/).

{{< tip >}}
Inside Reelio, drag a video onto a tag in the sidebar to tag it in one move. The tag entry highlights and the drag shows **Add tag** while you hover it. See [Tags](/docs/tags/).
{{< /tip >}}
